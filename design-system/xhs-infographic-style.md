# 小红书信息图风格（XHS Infographic Style）— Spec v1

> 平台无关的信息图规范，从「claude-dynamic-workflow-vs-deepseek-ptc」项目配图系列
> （2026-08 多轮实测）泛化而来。适用于小红书技术干货图文：决策对比图、流程图、
> 分层架构图、数据指标图、竖版长图封面。
> 哲学一句话：**白底 + 双色语义 + 严格文字层级 + 大量留白 = 高信噪比**。

---

## 1. 设计哲学（不可妥协的四条）

1. **纯白画布**：背景 `#ffffff`，不用浅灰底（浅灰底是公众号系风格，小红书系用纯白）。
2. **冷暖双色编码**：两个方案/两条路线用「青绿 vs 暖橙」区分（A 侧青绿 / B 侧暖橙），
   中性元素（提问卡、工具块、白卡）不占色。颜色是语义，不是装饰。
3. **文字层级 5 级**：粗黑大字 = 骨架（标题/结论），灰小字 = 血肉（说明/注释）。
   扫一眼粗体就能抓住全部要点。
4. **信息结构 = 认知结构**：决策图用「标题 → 提问 → 分支卡 → 结论条」动线；
   流程图用「节点 → 箭头 → 回环」动线；每张卡只讲一个观点。

## 4. 组件规范

### 4.1 卡片
- 大卡：`rx=24-26`，浅底 + 同色系描边 **3px**
- 白卡（中性节点）：`#ffffff` + `#9fb5c6` 描边 **2-3px**，`rx=14-16`
- 语义节点：浅底 + 同色系深描边（如 `#dff3ef` + `#4d9f98`）
- 胶囊标签：`rx=21`，`height=42`，浅色底（`#d8f0ed` / `#ffe9c9` / `#edf2fb`）
- 关键词色块（卡中卡）：`rx=12-16`，比大卡深一档的同色系底（`#d8f0ed` / `#ffe9c9`）

### 4.2 结论条
- 深色条：`rx=16-18`，`#18243a` 底 + 白字 24px / 700——**只放一行短口诀**
- 浅色条（替代方案，2026-08 用户偏好）：`#effaf8` 底 + `#176b65` 深字 24px / 700，
  可放两行（主句 + 灰字补充 18px `#65748b`）
- 竖版长图推荐浅色条（大块深色在长图上显得突兀）

### 4.3 箭头（⚠️ 最大坑，规范必读）

箭头 = **两段独立 path**：线段 + 箭头头（3 点折线，`fill="none" stroke-width="4"`）。

**箭头头画法**：3 点 = 翼角1 → 尖端 → 翼角2。
- **水平箭头**（朝右示例，参考文件同款）：
  ```
  <path d="M336 372 H408"/>                                <!-- 线 -->
  <path d="m398 360 18 12-18 12" fill="none" stroke-width="4"/>  <!-- 头 -->
  ```
  翼角 (398,360)/(398,384) **垂直排列**（x 相同、y 对称 ±12），尖端 (416,372) 在线上、
  伸出线端 8px、朝行进方向。
- **垂直箭头**（朝下/朝上）：翼角必须**水平排列**（y 相同、x 对称 ±12）：
  ```
  朝下：<path d="M510 846 V876"/>                                <!-- 线 -->
        <path d="m498 876 12 12 12-12" fill="none" stroke-width="4"/>  <!-- 头 -->
  ```
  翼角 (498,876)/(522,876) 水平排列，尖端 (510,888) 朝下指向目标。
  ```
  朝上：<path d="M570 900 V864"/>                                <!-- 线 -->
        <path d="m558 864 12-12 12 12" fill="none" stroke-width="4"/>  <!-- 头 -->
  ```
  翼角 (558,864)/(582,864) 水平排列，尖端 (570,852) 朝上。
- **错误示范**（2026-08-17 实测翻车）：垂直箭头误用垂直排列翼角
  `m498 874 12 12-12 12` → 尖端朝右，与垂直线的方向矛盾，视觉上"箭头头很奇怪"。

**箭头布局规则**：
- 线端停在翼角处（尖端 = 线端 + 8~12px 伸出，指向目标边界）
- 起点/终点必须精确对齐节点边缘，禁止悬空、禁止穿过卡片
- 回环/反馈箭头用虚线（`stroke-dasharray="10 6"` 或 `12 8`）+ 语义色；主线用 `#8092a8`
- 双向箭头水平错开（如 x=510 下行、x=570 上行），禁止重叠

## 5. 布局规则（实测踩坑）

1. **画布高度 = 内容底 + 40~60px**——不留大空白（2026-08 被用户连续批评"下方留白多/截得不完整"）
2. **文本溢出检查**：中文 ≈ 字号 px/字、ASCII ≈ 0.55×字号；文本必须落在父卡边界内
3. **长英文标签**（EXPERIENCE/OBSERVATION 等）：用左对齐 + 小一号字号（22px），
   禁止在窄卡里居中（会溢出左边界）
4. **行距**：body 与 small 基线差 ≥ 30px（16px 会叠字）；同一卡内文本基线差 ≥ 26px
5. **内边距**：子块与父卡边界 ≥ 20px（子块贴卡底 = 视觉 bug）
6. **竖版长图**：1080 宽，高度按内容（1400-2200 常见）；横版 1600×900（@2x 渲染）
7. **文字层级克制**：一张图只讲一个观点，关键信息粗黑、辅助信息灰小

## 6. 内容结构（小红书图文）

### 6.1 标题（≤20 中文字）
- 对仗金句：「一个管一群AI，一个管一个AI的一堆活」
- 悬念钩子：「AI终于会"改变想法"了」
- 品牌+定位：「开源记忆Hindsight：AI终于会学习了」
- 带英文品牌时计入字符（Hindsight = 9 字符）

### 6.2 正文结构（爆款模板）
1. 悬念开场（两个名字总被比较 / 场景痛点）
2. 转折（但它们解决的根本不是同一个问题）
3. ✅ 定义（每方案一句话本质 + 适用场景）
4. 📌 金句（可转发的一句话记忆点）
5. 🏆 数据（3-4 组硬指标）
6. 升华金句（观点输出，制造收藏理由）

### 6.3 图序（信息图是主体，正文是引导）
`封面（是什么+怎么做+有什么用+数据）→ 全局图 → 内部细节 N 连（竖版）→ 对比 → 场景 → 数据 → 收尾`

### 6.4 标签
5-7 个细分垂类（含产品名/技术词），如 `#Hindsight #AI #Agent记忆 #RAG #大模型 #开源 #程序员`

## 7. 检查工具

`engines/svg/svg_check.py <file.svg>...`——自动检查：
- 画布余量（内容底 vs 画布高，>80px 报"留白过多"）
- 文本超出画布 / 无卡片包含（溢出检测，中文=字号、ASCII≈0.55×字号 估算）
- 输出每张图的问题清单（退出码 0=干净，1=有问题）

**工作流**：SVG 写完后**必跑检查** → 修复 → `html_to_image.py` 渲染 → 交付/发布。
