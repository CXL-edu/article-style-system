# 组件规范（Components）— 通用视觉规范

> 双色对比排版系统的组件层规范：表格 / 引用 / 代码块 / 图片 / 封面 / 信息图。
> **平台无关**：以下数值均为通用基线，与具体平台无关；配色取自 tokens 实例（默认 `wechat-light-v2` 蓝橙）。
> 换主题只替换 tokens，组件结构与数值基线不变。

## 0. 通用基线

| 维度 | 基线值 | 说明 |
|---|---|---|
| 正文字号 | 15–16px | 移动端阅读舒适区间 |
| 正文行高 | 1.75–1.9 | 中文排版松弛感 |
| 圆角 | 小元素 4px / 卡片 8px / 封面大卡 12px | 分级圆角 |
| 间距基准 | 4px 网格 | 所有 margin/padding 为 4 的倍数 |
| 字体栈 | `-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif` | 系统字体优先，无需外挂字体 |
| 等宽字体 | `ui-monospace, "SF Mono", Menlo, Consolas, monospace` | 代码专用 |
| 描边 | 1px `border` 色 | 卡片、表格、图片 |

---

## 1. 表格

**规范要点**
- 表头：`accent` 色浅底 + 600 字重；表头是结构不是语义，**不上 A/B 色**
- 单元格：`text` 正文色、13–14px、行高 1.6、垂直居中
- 边框：仅横向细分隔线（1px `border` 色），不画纵向线；首末行可用粗线收口
- 斑马纹：可选（极浅灰 `#F8FAFC` 级），对比型内容默认不用
- 表格内的 `{{术语}}` 着色**照常生效**（表格属于正文内容，不是引用）

**实现建议**
- 输出 `<table>` + inline style：`border-collapse: collapse; width: 100%`
- 单元格 padding：`8px 12px`（表头同）
- 宽表优先「精简列」而非横向滚动；必要时允许横向滚动容器，禁止压缩换行破坏对齐

## 2. 引用框

**规范要点**
- 结构：左侧 3–4px `accent` 色条 + `quote_bg` 浅底 + `quote_text` 深蓝灰文字
- 圆角 8px、内边距 `12px 16px`、上下外间距 `16px 0`
- **框内不上色**：`{{术语}}` 降级为 `neutral` 600 字重；`==金句==` 降级为 `neutral` 加粗；行内代码/链接保持中性变体
- 字号 14px、行高 1.7，比正文略小以区分层级

**实现建议**
- 渲染器把 `<blockquote>` 输出为 `div` + inline style，左条用 `border-left`（平台粘贴保真，不用背景渐变模拟）
- 引用内术语降级在渲染阶段完成（渲染器契约），勿留给平台侧处理

## 3. 代码块

**规范要点**
- 整块代码：深色底（默认 `#1E1E1E`）+ 浅色等宽字（`#D4D4D4`）、圆角 8px、内边距 `12px 16px`
- 语法高亮沿用编辑器惯例色（绿/橙/蓝/浅绿），属编辑器语义，不算正文配色
- 行内代码：`code_inline_bg` 浅蓝底 + `code_inline_text` 深蓝字、圆角 4px、padding `2px 6px`
- 字号比正文小 1px（14px）、行高 1.5

**实现建议**
- 无高亮引擎时输出纯色块 + 等宽字体即可，不强依赖高亮
- 长代码允许横向滚动（`overflow-x: auto`），不要强制换行破坏缩进
- 代码块内的 `{{术语}}`、`==金句==` 不解析（代码是字面内容）

## 4. 图片

**规范要点**
- 正文插图：宽度 100% 自适应容器、圆角 8px、浅底图加 1px `border` 色描边
- 图注：`text2` 灰、12–13px、居中、与图片间距 8px
- 图片与上下文间距：上下 `16px`
- 清晰度：源图按 2x 分辨率导出（高清屏），导出宽度 ≥ 容器宽度 ×2

**实现建议**
- 输出 `<img>` + inline style，图注用 `<figcaption>` 或独立段落
- `max-width: 100%; height: auto`，禁止拉伸变形
- 截图类图片（代码/界面）整图呈现，避免压缩到糊

## 5. 封面

**规范要点**
- **画布比例 2.35:1**（信息流通用横幅比例），原生画布 1242×528（≈2.35:1）
- 布局：左侧标题区（大标题 + 副标题），右侧或底部品牌区；A/B 双色渐变分隔条
- 标题 36–44px 粗体、`text` 色；副题 16–18px、`text2` 色
- 「XX版」pill：A/B 色填充 + 白字 + 圆角 999px（注意结构规则：引用框内不重复此标签）
- 背景纯色或极浅渐变（A/B 两色 5–10% 透明度），文字与背景对比度 ≥ 4.5:1

**实现建议**
- 用 SVG 原生画布（见 `engines/svg-to-image/`）→ 无头 Chrome 导出 2x PNG，避免像素化
- 文字用系统字体栈，导出前检查字体渲染一致性
- 导出规格 2x（2496×1056 或同级），供高清图通道使用

## 6. 信息图

**规范要点**
- 画布宽 1080px（信息流标准），高度按内容自由（长宽比 ≤ 8:5 为宜）
- 卡片体系：圆角 12px、1px `border` 描边、内边距 24px、卡片间距 16px
- 颜色角色：标题 `text` 粗体 28px；正文 `text` 16px；强调数字用 A/B 色（语义性强调）
- 大数字/统计：A/B 色 + 800 字重（「术语着色」在数据场景的延伸）
- 底部统一落款区：品牌名 + 日期，`text2` 12px

**实现建议**
- 用 Pillow 流水线（见 `engines/image-pipeline/`）：画布 → 卡片 → 字体 → 导出
- 中文用系统中文字体，数字用等宽或同族字体；导出前做边界/碰撞检查（文字不溢出卡片）
- 导出一律 2x（2160 宽）再按平台压缩，保证清晰度
