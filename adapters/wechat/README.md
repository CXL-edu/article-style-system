# 公众号适配手册（最成熟 🟢）

> 链路：渲染器 → 微信 API 建草稿 → 网页版「发表」（需管理员扫码）→ 完成。
> 全自动程度最高：API 草稿 + 图片上传全自动；发表因未认证号限制走网页版。

## 链路总览

```
article.md（含 frontmatter）
  → engines/md-to-html/render_html.py 渲染（默认 wechat-light-v2 蓝橙配置）
  → 图片预处理脚本：media/uploadimg 上传正文图（本地路径 → mmbiz URL）
  → 建草稿脚本：draft/add 建草稿
  → 网页版后台「发表」（CDP 操作，管理员扫码）
```

## 关键要点

### 1. API 权限边界（未认证个人订阅号，实测）

| 接口 | 状态 |
|---|---|
| token / 素材上传 / draft/* | ✅ 可用 |
| freepublish/submit、mass/sendall | ❌ 48001（需认证） |
| 网页版「发表」（不推送） | ✅ 可用，每次管理员扫码 |

### 2. 编码坑（血泪教训）

- `json.dumps()` 必须 `ensure_ascii=False`！否则中文变 `\uXXXX` 字面量，网页端直接乱码
- author 字段 8 字节限制（UTF-8 字节算，非字符数）
- digest 上限 120 字（截取时先剥 `**`、`==`、`{{}}` 标记）
- frontmatter 剥离必须写在 `md_to_html()` 内部（模块调用时也要生效）

### 3. 正文图高清化

- 素材大小上限约 2MB
- 信息图（大量文字的架构图/流程图）源图分辨率不足是「发糊」根因
- 解法：SVG 源 → 无头 Chrome 渲染 2x（3200×1800）→ 重传 → 验证 CDN 尺寸
- 微信 CDN 不压缩：mmbiz URL 下载回来 = 上传原图字节（可用来验证）

### 4. 封面规范

- **必须原生设计 2.35:1**（1600×681 → 上传验证 1280×544），不要在 16:9 上裁剪（会切标题/结论）
- 封面带版本 pill（如「开发者版」）时，正文引用框内不要重复同义前缀

### 5. IP 白名单（40164）

- 出口 IP 变化（运营商重拨/VPN）会触发 40164
- 修复：开发者平台 → API IP 白名单 → 加上「微信实际看到的 IP + 本机直连出口」
- 点「确定」必须真实鼠标事件（CDP dispatchMouseEvent），`element.click()` 对 Vue 无效
- 弹二维码后从 DOM 提取原图（data:image base64）直接发用户远程扫，不要截图

### 6. 草稿生命周期

- `draft/add` 每次创建全新草稿 → 改文章时**不要新建**，用 `draft/update` 更新同一草稿
- 已发表文章想改 = 网页版「修改」（覆盖原文，不产生新文章）

## 工具

- 发布工具链（图片预处理脚本、建草稿脚本、沙箱发送脚本）位于本地工具目录 `<TOOL_DIR>`，不入库
- 凭证文件（AppID `<APP_ID>`、Secret 等）仅存于 `<TOOL_DIR>`，禁止提交到仓库
- 公众号：`<公众号名>`（个人订阅号，未认证）
- 凭证/工具链细节见 Hermes skill：wechat-publisher / wechat-mp-api / wechat-official-account
