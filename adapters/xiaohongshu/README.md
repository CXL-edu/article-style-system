# 小红书适配手册（次之 🟡）

> 链路：渲染器 → HTML 转长图（1080 宽）→ 小红书 MCP 全自动发布。
> 成熟度：发布自动化已通（MCP publish ✅），格式沉淀不如公众号完整。

## 链路总览

```
article.md
  → engines/md-to-html/render_html.py 渲染（双色对比设计系统）
  → engines/html-to-image/html_to_image.py 转长图（1080px 宽，适配竖屏信息流）
  → 小红书 MCP（`<MCP 工具名>`）：login → 启动服务 → publish_content 全自动发布
```

## 关键要点

### 1. 竖屏信息流特性

- 长图 1080×N（N 按内容长度，控制在 ~3000px 内体验最佳）
- 首图即封面：信息流里只露出第一屏，主视觉必须放最前
- 长图内已含全部排版（渲染器输出的 inline-style HTML 直接进长图）

### 2. 种草文案风格

- **标题**：种草干货风，emoji + 分点，可带 🔥 / 📍 / 💡
- **正文**：emoji 分点（📍💡✅❌），#话题标签 收尾
- **封面**：建议用文章主视觉图（对比图/封面图），不用单独重做

### 3. 与公众号的差异（仅输出端）

| 维度 | 公众号 | 小红书 |
|---|---|---|
| 输出形态 | HTML 直贴编辑器 | 长图 |
| 标题 | 摘要式 | 种草式（emoji） |
| 正文 | 排版规范全文 | 长图内已含全部排版 |
| 发布 | API 草稿 + 网页发表 | MCP 全自动 |

## 工具
