# 小红书适配手册（次之 🟡）

> 链路：确定性渲染器 → 1080 宽竖版图片 → 发布通道 → 公开页面复核。
> 发布接口可用不等于公开发布已验证；最终状态必须有公开笔记 URL 或账号笔记列表证据。

## 链路总览

```
article.md
  → engines/md-to-html/render_html.py 渲染（双色对比设计系统）
  → engines/html-to-image/html_to_image.py 转长图（1080px 宽，适配竖屏信息流）
  → 小红书发布通道：login → 发布 → 公开页面复核
```

## 关键要点

### 1. 竖屏信息流特性

- 竖版图片默认 1080×1440（3:4）；长图按内容长度生成时，建议控制在约 3000px 内
- 首图即封面：信息流里只露出第一屏，主视觉必须放最前
- 长图内已含全部排版（渲染器输出的 inline-style HTML 直接进长图）
- 纯白画布、青绿/暖橙双色语义、浅色结论条；标题不超过 20 个中文字符
- 箭头翼角方向、文本溢出、卡片内边距和底部留白必须在渲染后检查

### 2. 种草文案风格

- **标题**：种草干货风，emoji + 分点，可带 🔥 / 📍 / 💡
- **正文**：emoji 分点（📍💡✅❌），#话题标签 收尾
- **封面**：建议用文章主视觉图（对比图/封面图），不用单独重做

### 3. 与公众号的差异（仅输出端）

| 维度 | 公众号 | 小红书 |
|---|---|---|
| 输出形态 | HTML 直贴编辑器 | 长图 |
| 标题 | 摘要式 | 种草式（emoji） |
| 正文 | 排版规范全文 | 长图内已含全部排版 |
| 发布 | API 草稿 + 网页发表 | 发布通道 + 公开页面复核 |

## 工具

- 发布接口（如 MCP/OpenCLI）返回成功，只能记录为命令层结果；没有公开 URL 或账号笔记列表证据时，状态写“命令返回成功，公开状态待核验”
- 账号凭证和浏览器登录态只存于本地配置，不入库
- 详见 Hermes skill：xiaohongshu-publishing / api-free-social-publishing

## 踩坑日志

- 命令返回成功不等于公开笔记已发布；发布后必须保存公开 URL 或账号笔记列表证据。
- 技术信息图优先使用 SVG/Pillow 等确定性渲染，避免中文、数字和箭头出现生成错误。
